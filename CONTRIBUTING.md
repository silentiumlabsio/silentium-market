# Contributing

Thank you for helping improve SilentiumMarket.

This is a **public documentation and issue-tracking repository** for a closed-source project. The private implementation is not developed in this repository.

## Good public contributions

- documentation corrections;
- reproducible, sanitized bug reports;
- UX/feature feedback;
- public-facing wording improvements;
- redacted screenshots that clarify a user-interface issue.

## Please do not submit

- reconstructed or decompiled implementation code;
- private binaries or application archives;
- proprietary formulas/thresholds obtained from private builds;
- credentials, tokens, session data, account identifiers, or private logs;
- exploit instructions against player accounts or services;
- automation intended to perform RuneScape actions for the player.

## Bug reports

Use the bug-report template and remove all private data before submission. Include the SilentiumMarket version, affected surface, expected behavior, actual behavior, and safe reproduction steps.

## Documentation pull requests

Documentation-only pull requests are welcome. Keep changes limited to public material and avoid adding implementation claims that cannot be verified from the public project documentation.
