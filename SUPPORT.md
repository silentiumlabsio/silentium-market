# Support

For normal bugs and feature requests, use GitHub Issues and the provided templates.

For security-sensitive reports, follow `SECURITY.md` instead of opening a public issue.

When reporting a normal issue, include:

- SilentiumMarket version;
- affected surface (RuneLite cockpit, dashboard, planner, profit tracker, documentation);
- expected behavior;
- actual behavior;
- minimal safe reproduction steps;
- a redacted screenshot when useful.

Do not attach credentials, private databases, session information, or unsanitized logs.
