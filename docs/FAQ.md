# FAQ

## Is SilentiumMarket open source?

No. SilentiumMarket is a private, closed-source project. This repository contains public documentation and project information only.

## Can this repository be used to install SilentiumMarket?

No. Public application binaries and implementation source are intentionally not distributed here.

## Does SilentiumMarket guarantee profit?

No. No live-market system can guarantee profit. Prices, liquidity, and execution conditions can change after a recommendation is generated.

## Does SilentiumMarket guarantee zero false positives?

No. The project is designed to aggressively suppress false positives and expose uncertainty, but zero false positives cannot be guaranteed in a changing market.

## Does it automatically place GE offers?

No. Grand Exchange actions remain manual.

## Why separate personal and merch activity?

Players also use the GE for gear, supplies, quest items, and other non-merch purchases. Classification keeps those transactions from distorting merch performance statistics.

## Where should I report a security issue?

Follow `SECURITY.md` and do not post sensitive details publicly.
