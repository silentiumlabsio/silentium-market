# Public Roadmap

SilentiumMarket's public roadmap intentionally describes outcomes rather than proprietary implementation details.

## Reliability

- improve market-data health awareness;
- improve resistance to stale or inconsistent observations;
- improve diagnostic clarity when no plan is produced.

## Execution quality

- refine user-specific fill estimates from real observed outcomes;
- improve day-versus-night planning behavior;
- improve active-offer review guidance.

## Profit measurement

- improve separation of verified merch outcomes from unrelated GE purchases;
- improve long-term performance reporting and calibration.

## User experience

- reduce cockpit clutter;
- make rejection reasons easier to understand;
- make first-run behavior more obvious to new testers.

## Testing

- expand clean multi-user testing without sharing private runtime data;
- use observed results to refine reliability before wider distribution.
