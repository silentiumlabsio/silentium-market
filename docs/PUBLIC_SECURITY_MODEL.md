# Public Security Model

SilentiumMarket's public security posture is based on separation of concerns.

## Closed implementation

The private engine, RuneLite implementation, dashboard implementation, model internals, build configuration, and runtime schemas are not published in this repository.

## Local personal analytics

Personal market and execution history is intended to remain on the user's machine rather than being embedded in public project material.

## Public documentation boundary

Public material describes capabilities and limitations without publishing implementation details that would expose proprietary logic or private data structures.

## Issue-reporting boundary

Security-sensitive reports should be coordinated privately. Public issues should contain only sanitized reproduction information.

## Manual-execution boundary

The public product boundary keeps RuneScape actions manual and treats SilentiumMarket as analytics/decision support.
