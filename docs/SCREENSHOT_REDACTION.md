# Screenshot Redaction Guide

Screenshots are useful for bug reports, but they can expose more information than expected.

Before uploading a screenshot, check for and redact:

- character/display names;
- chat and private messages;
- account identifiers;
- browser tabs or session information;
- local file paths and Windows/Linux usernames;
- credentials, tokens, cookies, or developer-tool output;
- private tester names;
- any wealth/GP information you do not want public.

Crop the screenshot to the smallest region that still demonstrates the issue.
