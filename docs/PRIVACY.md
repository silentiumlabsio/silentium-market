# Privacy

SilentiumMarket is designed so personal trading analytics remain local to the user.

## Private information that should stay local

Examples include:

- observed GE fills and offer history;
- personal profit/loss records;
- watchlists;
- execution-learning data;
- account/session information;
- local application logs and databases;
- personal classification of GE activity.

## Public issue hygiene

Before posting a bug report or screenshot, remove any information you do not want public. Do not attach full runtime databases, credential files, environment files, or unsanitized logs.

## Tester separation

Each tester should use their own clean installation and local data. Users should not exchange personal runtime-data directories.
