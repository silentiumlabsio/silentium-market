# Public Repository Scope

SilentiumMarket is developed privately. This repository exists so the project can have a public identity without exposing the implementation or user data.

## Included publicly

- high-level product description;
- user-facing feature descriptions;
- sanitized public release notes;
- privacy, security, and responsible-use boundaries;
- issue and feedback workflows;
- high-level architecture diagrams that do not reveal private internals.

## Intentionally private

- market-engine source code;
- RuneLite plugin source code;
- dashboard implementation;
- build and launcher scripts;
- exact algorithms, weights, thresholds, formulas, and coefficients;
- private APIs and internal schemas;
- automated tests and private QA fixtures;
- runtime databases and user trading history;
- credentials, tokens, sessions, and local configuration;
- private tester packages and private manuals.

## Why this separation exists

The separation protects user privacy, prevents accidental credential/runtime-data exposure, and preserves proprietary research while still allowing transparent discussion of product behavior, limitations, and responsible-use boundaries.
