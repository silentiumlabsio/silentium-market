# Community Code of Conduct

## Our standard

Silentium Labs is committed to a respectful, constructive environment for everyone participating in the SilentiumMarket public repository.

Examples of positive participation include:

- communicating with patience and professional respect;
- giving specific, actionable feedback;
- respecting privacy, security boundaries, and differing levels of experience;
- keeping discussions relevant to the public documentation and user-facing project scope;
- accepting correction and taking responsibility for mistakes.

Unacceptable behavior includes:

- harassment, discrimination, threats, or personal attacks;
- publishing another person's private or identifying information;
- posting credentials, session information, account-sensitive data, or unsanitized private material;
- pressuring contributors to disclose private implementation details;
- deliberately disrupting issues, pull requests, or security-reporting channels;
- using project spaces to promote automation that performs RuneScape actions for a player.

## Scope

This code applies to public interactions within the repository, including issues, pull requests, reviews, and other project-managed community spaces.

## Enforcement

Project maintainers may edit or remove content and may restrict participation when behavior conflicts with these standards. Enforcement decisions will prioritize community safety, user privacy, responsible disclosure, and the repository's public-scope boundary.

Do not post sensitive conduct or security details in a public issue. Use GitHub's private reporting controls when applicable or contact the maintainer through an approved private channel.
