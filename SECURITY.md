# Security Policy

SilentiumMarket is a closed-source project. This public repository is intentionally limited to documentation and public project material.

## Reporting a security issue

Do **not** disclose security-sensitive findings in a public GitHub issue.

Prefer the repository's private vulnerability-reporting/security-advisory mechanism when available. If that is unavailable, contact Silentium Labs through its official public channel and include only the minimum information necessary to establish contact before sending sensitive technical details.

## Do not include

Never place the following in a public issue, discussion, screenshot, or attachment:

- Jagex/RuneLite session information or credentials;
- API keys, tokens, cookies, or environment values;
- character/account information you consider private;
- local file-system paths containing usernames;
- private SilentiumMarket binaries/source or decompiled material;
- runtime databases, trade-history exports, or unsanitized logs;
- security findings that would expose a user or private implementation detail before coordination.

## Supported public scope

Security reports about the public documentation repository itself are welcome. Reports about the private application should be coordinated privately.
